# Day 17: DynamoDB + Lambda Integration (October 30, 2025)

## What I Built Today
Created a serverless URL shortener backend using DynamoDB and Lambda functions. This is the foundation for Project #2 (URL Shortener API).

## Core Concepts Learned

### DynamoDB Operations
- **put_item**: Create new records with initial attributes (runs once per URL)
- **get_item**: Retrieve records by primary key (short_code)
- **update_item with ADD**: Atomic counter increment (safe for concurrent clicks)
- **update_item with SET**: Replace specific attribute values

### Lambda Function Structure
- Event-driven architecture: functions triggered by events
- Event parsing: extracting data from API Gateway format
- Response format: statusCode, headers, body (JSON)
- Error handling: try/except with proper HTTP status codes

### Key Insight: Atomic Operations
Learned the difference between operations:
- `create_short_url()` runs ONCE when URL is created
- `track_click()` runs MANY times (once per click)
- Atomic ADD operation prevents race conditions when multiple users click simultaneously

## What I Deployed

### Lambda Functions
1. **url-shortener-create**: Generates random 6-character codes, stores in DynamoDB
2. **url-shortener-get**: Retrieves URLs, tracks clicks, returns redirect response

### IAM Role
- Created `url-shortener-lambda-role` with DynamoDB and CloudWatch permissions
- Learned: IAM roles define what AWS services can do (principle of least privilege)

### Test Results
- Created short code `908SJa` → GitHub profile

- Both functions executed in ~300-350ms

```
    ↓

```
